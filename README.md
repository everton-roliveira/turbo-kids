# Turbo Kids

Jogo de corrida 3D para celular (Android e iPhone), feito para crianças.

## Como jogar
- Abra o `index.html` no navegador do celular (ou publique com GitHub Pages).
- Botões: acelerar, esquerda, direita e turbo (recarrega em 30 segundos).
- No computador: setas ou WASD, Espaço para o turbo, P ou Esc para pausar.

## Regras
- Fique entre os 3 primeiros para ir para a próxima pista. Se não, corre de novo.
- Cada posição ganha moedas. Use as moedas na garagem para melhorar motor, aceleração, amortecedor e pneus.
- Buracos deixam o carro lento. Bater numa faixa interditada zera a velocidade.
- Uma batida de lado tira o outro carro da pista, e os outros podem fazer o mesmo com você.
- 6 carros para escolher, com a cor que quiser. Os carros são inspirados em estilos famosos, sem marcas.

O progresso fica salvo no próprio celular.

Feito com [Three.js](https://threejs.org/), em um único arquivo HTML.
